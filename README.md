CANAL+ ASSISTANCE 24/7 — SITE WEB

Fichier principal : index.html

Mise en ligne gratuite :
1. Créez un compte GitHub.
2. Créez un nouveau dépôt (repository), par exemple canal-assistance-ebolowa.
3. Envoyez index.html dans le dépôt.
4. Activez GitHub Pages dans Settings > Pages.
5. Votre site recevra une adresse gratuite en .github.io.

Alternative : vous pouvez déposer le dossier sur Cloudflare Pages ou Vercel.

À personnaliser si nécessaire :
- Numéro WhatsApp/téléphone dans index.html
- Adresse exacte
- Horaires
- Services et tarifs
- Photos et logo
